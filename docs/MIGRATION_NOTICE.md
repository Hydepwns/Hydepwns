# Documentation Structure Migration Notice

## Overview

As part of our documentation consolidation efforts, we have reorganized several documentation directories to improve navigation and reduce fragmentation. This document serves as a reference for updated paths and redirections.

## Path Changes

The following directories have been moved or consolidated:

| Old Path | New Path |
|----------|----------|
| `docs/planning/*` | `docs/project/planning/*` |
| `docs/process/*` | `docs/project/process/*` |
| `docs/design/*` | `docs/development/design/*` |

## Action Required

If you maintain any external links or references to our documentation, please update them according to the path changes above. All internal cross-references have been updated to reflect these changes.

## Benefits

This reorganization:
- Reduces documentation fragmentation
- Improves logical grouping of related content
- Simplifies navigation and maintenance
- Consolidates project management documentation
- Integrates design documentation with development resources

## Questions or Issues

If you encounter any broken links or have questions about the new structure, please:
1. Check this migration notice for the new path
2. Consult the main [Documentation Map](DOCUMENTATION_MAP.md)
3. Raise an issue if you still can't find what you're looking for

## Timeline

These changes were implemented on March 14, 2025. All redirects will be maintained for at least 6 months from this date.
