# Documentation Archives

This directory contains archived documentation that has been superseded by newer versions or is no longer actively maintained.

## Archive Structure

Each archive is organized by date in the format `YYYY-MM-DD`. For example:
- `2025-03-14/` - Documentation archived on March 14, 2025

## Current Archives

### March 14, 2025 Archive
- Contains the old PRD directory structure that was consolidated into the new documentation organization
- See [2025-03-14/ARCHIVE_NOTICE.md](2025-03-14/ARCHIVE_NOTICE.md) for details about what was archived and where to find the current versions

## Archive Policy

- Archives are retained for 6 months from their creation date
- Each archive includes an ARCHIVE_NOTICE.md file explaining:
  - What content was archived
  - Why it was archived
  - Where to find current versions of the documentation
  - The retention period
- After the retention period, archives may be permanently removed

## Finding Current Documentation

For current documentation:
1. Start with the [Documentation Map](../DOCUMENTATION_MAP.md)
2. Check the [Migration Notice](../MIGRATION_NOTICE.md) if you're looking for recently moved content
3. Use the search functionality in the documentation portal

## Questions or Issues

If you can't find what you're looking for:
1. Check the ARCHIVE_NOTICE.md in the relevant archive directory
2. Search the current documentation structure
3. Raise an issue if you still can't find what you need
