## Contributing

When adding new getting started guides:
1. Follow the documentation style guide in `docs/design/style-guide.md`
2. Include clear prerequisites
3. Use step-by-step instructions
4. Add troubleshooting sections for common issues
5. Include links to more detailed documentation
